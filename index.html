Automação de testes NSTECH

Suíte interna de testes automatizados (Playwright) usada pelo time de QA da NSTECH para validar o sistema MultiTMS antes de cada entrega. Não é um produto voltado ao público — esta página existe para documentar, de forma transparente, o que a suíte acessa e por quê.

uso interno escopo: gmail.readonly somente leitura

O que a suíte faz

Alguns fluxos de teste (redefinição de senha, primeiro acesso) dependem de um código ou link enviado por e-mail. A suíte lê esse e-mail para poder concluir o fluxo sozinha, sem depender de alguém abrir a caixa de entrada manualmente durante a execução.

  • ✓
    Lê e-mails da própria caixa de automação
    Uma conta dedicada, criada só para isso: automacao.nstech@gmail.com.
  • ✓
    Procura por remetente e assunto conhecidos
    Filtra mensagens do próprio MultiTMS dentro de uma janela de poucos minutos após disparar o teste.
  • ✗
    Não acessa contas de terceiros
    Nenhum dado de cliente, funcionário ou usuário final passa por essa suíte.
  • ✗
    Não envia, apaga nem encaminha e-mails
    O acesso é só de leitura — escopo gmail.readonly, nada além disso.

Como isso aparece em uma execução

Um exemplo real, resumido, de um dos passos de teste que depende do e-mail:

$ playwright test usuario.cpf.spec.ts
✓ Cadastrar usuário e disparar redefinição de senha (2.1s)
✓ Aguardar e-mail com a senha temporária (4.8s)
✓ Login com a senha recebida por e-mail (1.3s)
